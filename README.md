# Chat cliente-servidor en Python

Prototipos de chat por sockets, agrupando los primeros ejemplos y las versiones actuales.

## Ejecución

Abre dos terminales: inicia el servidor en una y luego ejecuta el cliente en la otra. Revisa cada script para confirmar la dirección y el puerto configurados.

Los archivos fuente se mantienen como estaban. Proyecto educativo en progreso.
